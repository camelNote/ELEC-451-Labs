\subsection{Circuit 3 --- Full-Bridge Rectifier with LC Filter and Resistive Load}
\label{sec:sim-c3}

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth]{sim_circuit3_schematic.png}
\caption{PSIM schematic of Circuit 3.}
\label{fig:sim-c3-schem}
\end{figure}

The THD can be calculated as (these are the source voltage and current):
\begin{equation}
\mathrm{THD} = \frac{\sqrt{\sum_{h \ne 1} I_{sh}^2}}{I_{s1}}
\end{equation}

equivalently...
\begin{equation}
I_s = I_{s1}\sqrt{1 + \mathrm{THD}^2}
\end{equation}
\begin{equation}
\frac{I_s^2}{I_{s1}^2} - 1 = \mathrm{THD}^2
\end{equation}

where $I_{s1}$ is the fundamental frequency of the source current.

We know at steady state, the $I_s = I_L = I_o$.
And since the load determines how much current flows through from the source,
\begin{equation}
I_{s1} = \frac{V_s}{R + R_{\mathrm{shunt}} + R_s}
\end{equation}
\begin{equation}
I_{s1} = \frac{12~\mathrm{V}}{500 + 1 + 2}
\end{equation}
\begin{equation}
\boxed{I_{s1} = 23.86~\mathrm{mA}}
\end{equation}
This is the fundamental component of $I_{s,\mathrm{RMS}}$ since the harmonic distortion comes from the current ripple.

Method: phasor analysis is used to find the output current, which is then converted to the time domain. Since the output is rectified, the final waveform is restricted to be positive, $i_o(t) = |I_o|\,|\sin(\omega t + \angle I_o)|$.

As shown in Fig.~\ref{fig:sim-c3-schem}, the source voltage after the source inductance and resistance drop is
\begin{equation}
V_{s2} = V_s - (j\omega L_s + R_s) I_s
\end{equation}
The output impedance seen by $V_{s2}$ is
\begin{equation}
Z_o = \left( \frac{1}{j\omega C} \parallel R \right) + j\omega L + R_{\mathrm{shunt}}
\end{equation}
At steady state $i_s = i_L = i_o$, so combining the equations gives
\begin{equation}
I_o Z_o = V_{s2}
\end{equation}
\begin{equation}
I_o Z_o = V_s - I_o (j\omega L_s + R_s)
\end{equation}
Solving for $I_o$ with the circuit values,
\begin{equation}
I_o = \frac{12}{0.002\,j\omega + 503}
\end{equation}
Converting to the time domain, with consideration for the rectified output,
\begin{equation}
\boxed{i_o(t) = 23.86~\mathrm{mA}\,\left|\sin(120\pi t - 0.001498)\right|}
\end{equation}
Note: $|I_o|$ equals $I_{s1}$ calculated earlier, which is a good sign.

Taking the Fourier series, the harmonic content can be analyzed as
\begin{equation}
|\sin x| = \frac{2}{\pi} - \frac{4}{\pi} \sum_{n=1}^{\infty} \frac{\cos(2nx)}{4n^2 - 1}
\end{equation}
\begin{equation}
|\sin(120\pi t)| = \frac{2}{\pi} - \frac{4}{\pi} \sum_{n=1}^{\infty} \frac{\cos(240\pi n t)}{4n^2 - 1}
\end{equation}
Since $i_o$ and $v_{s2}$ are essentially in phase, the harmonics can be approximated without accounting for the phase shift.

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{FourierAbsSinx.png}
\caption{Fourier-series reconstruction of $|\sin x|$ using the first 50 harmonics.}
\label{fig:fourier-abs-sinx}
\end{figure}

The peak of each harmonic (when the cosine equals one), ignoring the current amplitude, is
\begin{equation}
I_{p,n} = \frac{4}{\pi(4n^2 - 1)}
\end{equation}
The fundamental ($f = 120~\mathrm{Hz}$, $n = 1$) provides the most power, so the power contribution is compared as
\begin{equation}
\frac{I_{p,n}^2}{I_{p,1}^2} \times 100\%
\end{equation}
where $I_{p,1} = 4/(3\pi)$.

The fundamental is 60~Hz, and the THD is computed from the amplitudes in Table~\ref{tab:sim-c3-fft}:
\begin{equation}
\mathrm{THD} = \frac{\sqrt{(56.59^2 + 47.57^2 + 36.20^2 + 23.73^2 + 12.90^2 + 4.723^2)~\mathrm{mA}^2}}{62.68~\mathrm{mA}}
\end{equation}
\begin{equation}
\mathrm{THD} = \frac{86.76~\mathrm{mA}}{62.68~\mathrm{mA}} = 1.384
\end{equation}
\begin{equation}
\boxed{\mathrm{THD} = 138.4\%}
\end{equation}
